# Кот-вредитель 😼

Браузерная аркада: ты — кот, на столе стоят вещи хозяина, и все они, по мнению кота,
стоят там зря. Задача — сбросить со стола как можно больше за 60 секунд и не попасться.

## Правила

- Клик или тап по вещи — кот бьёт лапой, вещь летит на пол, ты получаешь очки.
- На клавиатуре работают клавиши <kbd>1</kbd>–<kbd>5</kbd> по местам на столе.
- Хозяин 🧑‍💻 работает — можно всё. Он оборачивается с 🤨 (это предупреждение), а потом
  смотрит прямо на тебя 👀 и загорается табличка «СМОТРИТ!». В этот момент трогать нельзя.
- Поймал — минус одно деление терпения и кот на секунду притворяется невинным. Три раза —
  выгоняют в коридор.
- Три успешных сброса подряд повышают множитель, максимум ×5. Попался — серия сгорает.
- Дорогие вещи (⌨️, 💻) подсвечиваются золотым: больше очков, но и звук громче.
- Рекорд хранится в `localStorage`, звук можно выключить кнопкой 🔊 в правом верхнем углу.

## На телефоне

Игра рассчитана и на тач: удар лапой срабатывает по `pointerdown`, без задержки клика,
двойной тап не зумит страницу, а падение вещи и поимка отзываются короткой вибрацией
(там, где браузер её поддерживает).

- Раскладка считает размеры сцены и от ширины, и от высоты, поэтому на узком высоком
  экране предметы не превращаются в мелкие точки, а в горизонтальной ориентации сцена
  уменьшается целиком и умещается по высоте.
- Кот стоит у правого края, а подсказки уходят в пустую часть стены слева — так они не
  перекрывают ни вещи на столе, ни самого кота.
- Учитываются вырезы и «шторки» экрана через `env(safe-area-inset-*)`, страница не тянется
  за края (`overscroll-behavior: none`).
- Подсказки про клавиши `1`–`5` на тач-устройствах скрыты — там они не нужны.
- Есть манифест и иконка, так что игру можно добавить на домашний экран и открыть без
  адресной строки.

Чтобы проверить на своём телефоне, запусти дев-сервер с доступом по сети и открой на
телефоне адрес вида `http://<ip-компьютера>:43317`:

```bash
npm run dev -- --host
```

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Дев-сервер поднимается на [http://127.0.0.1:43317](http://127.0.0.1:43317).

Прод-сборка и её локальный просмотр:

```bash
npm run build     # tsc + vite build, результат в dist/
npm run preview   # раздаёт dist/ на порту 43318
npm run typecheck # только проверка типов
```

## Как всё устроено

Обычный Vite + TypeScript без фреймворка: игра — это DOM-элементы, эмодзи и CSS-анимации.

| Файл            | Что внутри                                                                     |
| --------------- | ------------------------------------------------------------------------------ |
| `index.html`    | Разметка сцены: стена, стол, хозяин, кот, HUD, оверлей с карточками             |
| `src/game.ts`   | Класс `Game`: состояние раунда, цикл внимания хозяина, очки, серии, анимации    |
| `src/data.ts`   | Вещи со стола, их стоимость и шутки, реплики хозяина и кота, звания в финале    |
| `src/audio.ts`  | Звук на Web Audio API — синтезируется на ходу, без файлов; выключатель со сроком жизни в `localStorage` |
| `src/style.css` | Вся графика: комната, стол, свет лампы, тряска, падение вещей, мусор на полу    |

Цикл внимания хозяина ускоряется к концу раунда: паузы между взглядами сокращаются,
а сами взгляды становятся длиннее, так что последние секунды играются заметно нервнее.

Игра уважает `prefers-reduced-motion`, работает с клавиатуры, а раскладка подстраивается
под телефон и низкие окна.
